# Cost statement

- Application libraries are open source: Streamlit, SQLAlchemy, Requests, BeautifulSoup, pandas, ReportLab, pytest, and Python's standard library.
- Persistence is local SQLite; uploads and reports are stored locally.
- Crawling uses public websites and RSS/Atom endpoints, subject to each site's terms, robots rules, and access limits. Optional search uses Tavily's free Researcher plan, which currently includes 1,000 monthly credits without a credit card; requests stop when credits are exhausted unless the account upgrades or enables pay-as-you-go. See [Tavily pricing](https://www.tavily.com/pricing). Search is disabled by default; an API key is required to enable it.
- Optional public-signal classification uses OpenRouter's `perplexity/pplx-decider-flash-v1.3:free` Decisions model; optional brief prose synthesis uses the separate `openai/gpt-oss-120b:free` text model. Both are listed at $0 token pricing and require an OpenRouter account/API key; the free endpoints are rate limited. See the [Decider model](https://openrouter.ai/perplexity/pplx-decider-flash-v1.3%3Afree), [GPT-OSS model](https://openrouter.ai/openai/gpt-oss-120b%3Afree), and [free-model rate-limit details](https://openrouter.ai/collections/free-models). The app rejects model IDs without the `:free` suffix. Brief synthesis is opt-in and sends the company name, public signal excerpts, and source-stated profile fields. Internal uploads and founder answers stay local. This environment has no configured provider credentials, so no live call or usage cost was measured.
- The application itself has no hosting charge in its local setup. Internet, electricity, local compute/storage, and any chosen deployment costs are outside the code's control.
- No public deployment or persistent hosted scheduler has been configured. No live search, model, or source-crawl requests were run for this audit.
