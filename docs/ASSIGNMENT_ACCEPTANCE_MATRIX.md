## Free-service references checked

- OpenRouter lists [`perplexity/pplx-decider-flash-v1.3:free`](https://openrouter.ai/perplexity/pplx-decider-flash-v1.3%3Afree) as a structured decision model, not a text generator. Signal classification uses this Decisions API model.
- OpenRouter lists [`openai/gpt-oss-120b:free`](https://openrouter.ai/openai/gpt-oss-120b%3Afree) as a free text model with structured-output support. It is configured separately for brief prose synthesis via Chat Completions.
- Tavily's [Researcher plan](https://www.tavily.com/pricing) currently offers 1,000 monthly API credits without a card. This app does not enable billing or upgrade an account.

## Evidence and remaining blockers

The full local suite and per-requirement tests are summarized in [test evidence](test-evidence.md); measured company counts are in [the acceptance report](DEMO_ACCEPTANCE_REPORT.md). The local runtime has no OpenRouter/Tavily provider credentials. Live source validation, human approval, company uploads, persistent hosting, GitHub publication and recording remain necessary to demonstrate the assignment's minimum output. No fixture or candidate is counted as real evidence.
