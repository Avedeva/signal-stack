## Current conclusions

- Local security and regression work covers authenticated production startup, ORM principal enforcement, persisted brief sanitization, a bounded/deadline-aware crawler, scheduler cleanup, chronological feed order, existing-signal score recalculation, verification history, source-upsert preservation, internal CSV/XLSX analysis, and opt-in search-provider handling.
- `services/analysis_pipeline.py` isolates event extraction, company impact, recommendation and confidence stages. Monday briefs now offer explicit, optional OpenRouter synthesis for public signals, with quote matching, privacy filters, and deterministic fallback. The Perplexity Decider model is used only for structured decisions; prose synthesis uses a separate free chat model. Both provider paths enforce `:free` model IDs. This does not replace evidence review or establish verification.
- Optional Tavily search is integrated as a discovery provider. It is disabled by default, excludes founder answers/uploads, records provider snippets as unverified search provenance, and does not auto-approve or create factual company claims.
- A Docker Compose deployment is prepared with production auth secrets, a non-root user, a migration step, local persistent volumes, a loopback-only host binding and a health check. Docker is not available in this environment; build/startup/deployment remain unverified.
- Automated competitor relationship research/profile cross-checking, company claim cross-checking, per-source refresh intervals, multi-user/per-company ACLs, transitive dependency lock, and live source collection remain incomplete. Competitor candidates now have structured editable profile fields and supporting-source provenance, but evidence counts remain zero.
